# SUNNY'S Game Cafe — Luxury Editorial Web Application

A modern, high-performance React web application designed for **SUNNY'S Game Cafe**, Nagpur's premier boutique gaming lounge and VR studio, located on London Street, Khamla.

## 🎨 Design System & Aesthetic
Built using the **"Luxury Editorial Web Design"** (Boutique Magazine Lookbook) architecture:
- **Typography:** *Cormorant Garamond* (dramatic Serif with italic accents) paired with *Plus Jakarta Sans* (clean Sans-Serif).
- **Aesthetic:** Deep Obsidian night backdrop (`#070A11`), Champagne Gold metallic accents (`#D4AF37`), Neon Violet/Cyan ambient glows, and ultra-thin 1px low-opacity luxury borders.
- **Glassmorphism:** Frosted-glass panels with 24px backdrop blur.

## 🚀 Key Features
- **Consoles & Hardware Menu:** Showcase of PlayStation 5, Xbox Series X/S, Meta VR Headset, Force-Feedback Steering Rig, PS4 Pro, and Retro PS2.
- **Filterable Games Archive:** Interactive category filters for Action & Adventure, Sports & Racing, Fighting & Multiplayer, and VR Immersion (GTA V, EA Sports FC 25, Tekken 8, Spider-Man 2, Gran Turismo 7, etc.).
- **Transparent Rates & Console Rentals:** Menu-board pricing packages for casual hourly play and take-home console rentals.
- **Verified 5.0★ Testimonials:** Real patient/gamer reviews from Google Maps.
- **Interactive WhatsApp Booking Engine:** Dynamic slot reservation generator sending pre-formatted messages directly to `+91 70288 38447`.
- **Location & Dark-Mode Map Embed:** Embedded interactive Google Maps for Plot No. 5, Jaitala Mini Ring Road, Khamla, Nagpur.

## 🛠️ Tech Stack
- **Framework:** React 18 (Vite)
- **Styling:** Tailwind CSS (Custom Editorial Theme)
- **Icons:** Lucide React
- **Hosting Compatibility:** Vercel, Netlify, GitHub Pages

## 📦 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/ekaivaBadal/sunnyclient.git

# Navigate into project
cd sunnyclient

# Install dependencies
npm install

# Start development server
npm run dev
```
